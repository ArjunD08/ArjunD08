## Autonomous Anti-Jamming Response System for Drones

**Embedded AI · RF Signal Analysis · Machine Learning · STM32 · NRF24L01 · TensorFlow Lite**

A compact embedded system designed to detect abnormal RF conditions and classify potential communication interference using machine-learning techniques.

**Key technologies:**
- STM32F411
- NRF24L01+PA+LNA
- ESP-01
- TensorFlow / TensorFlow Lite
- CNN
- LSTM / GRU
- RSSI time-series analysis
- Spectrogram-based classification
- Anomaly detection

> Research-oriented project combining embedded systems, RF signal analysis and AI at the edge.
